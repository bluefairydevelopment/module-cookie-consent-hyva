# BlueFairy Cookie Consent for Hyvä: Features

Included with BlueFairy Cookie Consent ($25).

- Alpine.js banner and preferences centre, no RequireJS, jQuery or Knockout.
- Reject all as prominent as Accept all; Customise with per-category switches.
- "Cookie settings" button to reopen preferences after a choice.
- Tailwind sources registered automatically with Hyvä's config generator.
- Full-page cache safe: the same HTML for every visitor.
